# Responsive Login Page

A modern and responsive **Login Page** created by **Fahim Montasir** using **HTML, CSS, and JavaScript**. This project focuses on creating a clean, attractive, and user-friendly interface with a strong emphasis on **CSS styling**. It is designed to work seamlessly across mobile, tablet, and desktop devices.

## 🚀 Features

- 🎨 Modern and clean UI design
- 📱 Fully responsive for all screen sizes
- ⚡ Built with HTML, CSS, and JavaScript
- 💻 Cross-browser compatible
- 🧩 Easy to customize and extend
- 🚫 Frontend-only (No authentication or backend integration)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
